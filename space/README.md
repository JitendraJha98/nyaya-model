# Nyaya — retrieval demo

The statute retriever behind the Nyaya Indian legal guidance system: type a
question in English, Hindi or Hinglish and see the sections of current law
(BNS / BNSS / BSA post-July-2024, the Constitution and ten other acts) it
resolves to, with a coverage verdict. Retrieval only, CPU only; the reader model
is documented at
[NyayaLabs98/nyaya-3b-v3](https://huggingface.co/NyayaLabs98/nyaya-3b-v3).

Code and data: [github.com/JitendraJha98/nyaya-model](https://github.com/JitendraJha98/nyaya-model).
**Not legal advice.**
